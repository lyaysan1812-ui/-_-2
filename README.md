# Семейный бюджет

Небольшой сайт для учёта семейных доходов и расходов. Всё считается в браузере: регистрация не нужна, цифры не уходят на сервер.

## Страницы

- `index.html` — короткое приветствие: зачем калькулятор и как им пользоваться.
- `app.html` — сам учёт: месяц, лимит, операции, сводка по категориям, таблица и экспорт CSV.

Старые записи из одного файла «Калькулятор СБ» читаются как раньше: ключи `localStorage` не менялись.

## Как открыть

Дважды щёлкните `index.html` или запустите любую статическую раздачу из этой папки, например:

```bash
npx --yes serve .
```

Калькулятор открывается кнопкой «Перейти к учёту».

## Что сохраняется

| Ключ | Содержимое |
| --- | --- |
| `family_budget_operations_v1` | операции |
| `family_budget_limits_v1` | лимит расходов по месяцам |
| `family_budget_theme_v1` | светлая или тёмная тема |

Очистка данных сайта в браузере удаляет этот учёт. Копия месяца — кнопка «Скачать CSV».
